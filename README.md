# Maviya Minza - Portfolio

A personal portfolio website showcasing my background as a Computer Science and Engineering student, my UI/UX work, certifications, achievements, and contact details.

**Live website:** [maviyaminza.github.io/portfolio](https://maviyaminza.github.io/portfolio/)

## Highlights

- Responsive single-page portfolio layout
- Downloadable resume
- Skills, education, experience, achievements, and certifications sections
- FreshSip and FitLife project showcases
- Contact form powered by FormSubmit
- Smooth section-reveal animations and a mobile navigation menu

## Built with

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Run locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Project structure

```text
portfolio/
|- assets/       # Resume PDF
|- css/          # Website styles
|- images/       # Project images and certificates
|- js/           # Website interactions
`- index.html    # Main webpage
```
